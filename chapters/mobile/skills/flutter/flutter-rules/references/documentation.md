# Flutter Rules — Documentation

Source: Mobile Flutter Developer Rules v1.0 — Domain: Documentation

## README

- Ensure a clear, concise but detailed README in every project.

## Evaluation Criteria

A Flutter project README must include at a minimum:

- Project description and its purpose.
- Installation and development environment setup instructions.
- Explanation of the project architecture and structure.
- Dependency rules between layers (Domain, Data, Presentation).
- Instructions for running and building each flavor/environment.
- Instructions for running unit and integration tests.
- Contribution guide (commit conventions, branches, PRs).
- References to relevant external documentation (libraries, APIs, design).
