# Prompts del stack serenity-wdio

Este directorio agrupa los prompts específicos del stack `serenity-wdio` del chapter `calidad`.

Los prompts habilitan la generación asistida de artefactos del arquetipo basado en TypeScript, WebdriverIO v9, Serenity/JS v3.31 y Cucumber 11, con soporte multiplataforma para web, web_movil, movil, desktop y api.

Aquí residen los prompts de alcance stack (por ejemplo, generación de features Cucumber, generación de tasks Screenplay y validación de inputs obligatorios), cada uno con su frontmatter canónico y una sección `## Template`.
