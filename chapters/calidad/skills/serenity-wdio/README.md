# Skills del stack serenity-wdio

Este directorio agrupa los skills específicos del stack `serenity-wdio` del chapter `calidad`.

El stack `serenity-wdio` corresponde al arquetipo de automatización basado en TypeScript, WebdriverIO v9, Serenity/JS v3.31 y Cucumber 11, con soporte multiplataforma para web, web_movil, movil, desktop y api.

Aquí residen los skills de alcance stack (por ejemplo, generación greenfield, extensión brownfield y ejecución por modos y tags), cada uno con su propio `SKILL.md` y, cuando aplique, una carpeta `references/` con detalle extendido en markdown plano.

Los skills de este stack reutilizan los assets transversales del chapter mediante enlaces con el prefijo canónico `calidad-`, sin duplicar su contenido.
