# Workflows del stack serenity-wdio

Este directorio agrupa los workflows específicos del stack `serenity-wdio` del chapter `calidad`.

Los workflows describen procesos reproducibles para el arquetipo basado en TypeScript, WebdriverIO v9, Serenity/JS v3.31 y Cucumber 11, con soporte multiplataforma para web, web_movil, movil, desktop y api.

Aquí residen los workflows de alcance stack (por ejemplo, generación de proyecto nuevo, extensión de proyecto existente y resolución de localizadores diferidos), cada uno con su frontmatter canónico y una sección `## Pasos` enumerada en orden secuencial ascendente.
